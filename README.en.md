# Jeomseon Unity Singleton

Provides scene, persistent MonoBehaviour, and ScriptableObject singleton base types from JeomseonScriptPack.

## Requirements

- Unity 2022.3 or newer

## Installation

```json
{
  "dependencies": {
    "com.jeomseon.unity.singleton": "0.1.0"
  }
}
```
